# Pythonator

Mod do Factoria 2.1: programovatelný obvodový kontrolér, který se programuje v podmnožině Pythonu.
Každý tick: načíst vstupy → `loop()` → zapsat výstupy.

- Návrh: `docs/specs/2026-10-09-pythonator-design.md`
- Uživatelská příručka: `docs/user-guide.md`
- Vývoj a testy: `docs/development.md`
- Popis pro mod portál (EN): `docs/mod-portal.md`, publikace: `docs/development.md` → Publikace

Rychlý start vývoje: `bash tools/run-unit.sh`
